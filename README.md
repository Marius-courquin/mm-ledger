# MM Ledger

Personal ledger for Trade Republic portfolio tracking.

## Prerequisites

- [Bun](https://bun.sh/) (v1.0+)

## Getting started

```bash
# Install Bun
curl -fsSL https://bun.sh/install | bash

# Install dependencies
bun install

# Run the project
bun run start
```

## Design

The global design is maintained in `global-design.pen` and can be viewed/edited using [Pencil](https://pencil.li/).
